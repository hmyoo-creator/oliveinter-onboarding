# 올리브인터내셔널 입사 전 안내사항

입사 예정자에게 보내는 안내 페이지예요. 고용형태와 근무제에 따라 4개 버전이 있어요.

| 버전 | 주소 |
| --- | --- |
| 정규직 · 시차출퇴근제 적용 | `사이트주소/regular-flex` |
| 정규직 · 시차출퇴근제 미적용 | `사이트주소/regular-fixed` |
| 인턴·계약직 · 시차출퇴근제 적용 | `사이트주소/intern-flex` |
| 인턴·계약직 · 시차출퇴근제 미적용 | `사이트주소/intern-fixed` |

## 문구 고치기

문구는 모두 `content` 폴더에 있어요.

| 파일 | 내용 |
| --- | --- |
| `content/common.js` | 4개 페이지 공통 (인사말, 오시는 길, 기본 정보, 복지, 준비물, 온보딩 링크, 맺음말) |
| `content/regular-flex.js` 외 3개 | 버전별 근무 시간, 복지 구분(정규직/인턴) |

- 복지는 `common.js`에 모두 있고, 항목마다 `대상`이 "전체" / "정규직" / "인턴" 중 하나예요.
- GitHub에서 파일을 열고 연필 아이콘 → 따옴표 안 문구만 수정 → **Commit changes**. 1~2분 뒤 사이트에 반영돼요.
- 줄 끝 쉼표는 지우지 않아요. 굵게 `**글자**`, 줄바꿈 `\n`, 링크 `[글자](주소)`.

## 사진 바꾸기

`assets` 폴더에 같은 이름으로 다시 올리면 돼요: `logo.png`(로고), `map.jpg`(지도), `elevator.jpg`(엘리베이터).
